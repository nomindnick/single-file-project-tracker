How to use / trouble saving?
  1. In NetDocuments, use Check Out & Download on this file (don't just click it open — changes made that way are lost).
  2. Open the downloaded file in your browser (it's usually in your Downloads folder).
  3. Click “Connect to this file” once and pick this same file in the window that opens.
  4. Make your changes, then click Save.
  5. When you're done, check the file back in to NetDocuments (pick the saved file from your Downloads folder).
